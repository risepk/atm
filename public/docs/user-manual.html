Section 1

Overview & Core Philosophy

ATM Ledger is a high-speed, institutional-grade Account & Transaction Management platform engineered for corporate treasury, financial accounting, and high-volume transaction recording.

Dynamic Narration

Smart pattern templates with auto-detected fields and random reference generators.

Zero Float Math

All currency operations execute strictly via 18,2 fixed-point BCMath with zero binary drift.

Permanent History

Transactions link to permanent numeric account IDs. Account renames never corrupt historical statements.

Creating Custom Accounts: Click "+ New Account". Enter an account title, select the banking institution from the searchable dropdown, and enter your account or IBAN number. Set the starting opening balance.
Strict Opening Balance Immutability: Before any transactions are posted, an account's initial balance may be updated freely. Once the first financial transaction is posted to an account, the initial balance becomes permanently locked to ensure audit compliance.
Renaming & Account Status: Accounts can be safely renamed at any time without corrupting past transactions. If an account is decommissioned, set its status to Inactive or Closed; closed accounts preserve past ledger history but disallow new entries.
Section 4

Rapid vs Detailed Transaction Entry

ATM Ledger provides two specialized transaction entry workflows tailored for different operational needs:

A. Rapid Transaction Entry (/transactions/rapid) — High-Speed Batch Posting

Primary Default Mode

Designed for high-speed continuous posting for a single account without repeatedly selecting the account or navigating through heavy dynamic configuration screens.

1. Manual Narration (Fastest)

Type description directly in the main narration box. Ideal for cash vouchers, store receipts, utility payments, and unique one-off transactions. Amount is cleared and auto-focused after save.

2. Quick Narration Mode (Optional Helper)

Click "+ Use Quick Narration" to open an inline compact template helper. Select common banking templates (IBFT, Funds Transfer, ATM, Cash Deposit) to auto-compile standardized narration.

Key Rapid Entry Capabilities:

  • Persistent Account Lock: Select the account once; it stays locked across consecutive submissions.
  • Retained Date & Flow: Transaction date and Debit/Credit toggle persist across entries (Alt+D / Alt+C).
  • Dynamic Required Inputs Only: Shows only essential inputs for the chosen template (e.g. Sender Name, Bank, Account). No technical JSON or developer metadata.
  • Compact Generator Refresh (↻): Click the inline refresh icon to regenerate unique STANs or bank reference numbers instantly.
  • 1-Click Preset Loading: If presets exist for the template, select from the compact dropdown to pre-fill counterparty details.
  • Real-Time Narration Compilation: Narration compiles live directly into the primary description field as you type.
  • 100% Freely Editable: You can still edit or append to the final compiled text before saving.
  • Template Retention Across Entries: The selected Quick Narration template stays active between saves while clearing only transaction-specific inputs.
  • Instant BCMath Balance Verification: Live available balance updates in the header card on every submission.
  • Immediate Focus Reset: Amount is cleared and auto-focused after save; press Ctrl+Enter to save.

B. Detailed Transaction Entry (/transactions/detailed) — Advanced Mode

Template Engine Mode

Preserves 100% of the advanced narration template engine for structured, multi-line pattern configuration, deep preset management, and real-time live preview panels:

  • Database-Driven Templates: Comprehensive template library with full field definitions.
  • Live Pattern Compilation Preview: Visual comparison between dynamic fields and compiled output.
  • Create & Save Presets: Save active field combinations as personal or global counterparty presets.
  • Authoritative Final Textarea: Independent multi-line textarea with manual override indicators and re-sync trigger.

Operational Decision Guide: When to Use Each Mode

Operational Scenario Recommended Mode Key Advantage
Entering daily bank statements (10-50+ transactions) Rapid Entry (Manual / Quick) Locked account, Amount auto-refocus, Ctrl+Enter, zero lag.
Repetitive transfers with auto STAN / Reference numbers Rapid Entry (Quick Narration) Keeps template selected, auto-generates fresh unique STAN per save.
Creating reusable beneficiary presets for your team Detailed Entry Preset creation dialog with Global/Personal scope configuration.
Complex transactions requiring multi-line breakdown Detailed Entry Multi-line textarea, pattern comparison, field re-syncing.
Section 5

Narration Engine & Dynamic Fields

The Narration Engine generates standardized, bank-compliant transaction descriptions automatically:

1. Select a Template: Select a template such as IBFT Transfer, Cash Deposit, or Vendor Bill Payment.

2. Dynamic Fields Appear Instantly: The interface generates the precise fields required by the pattern (e.g. Sender Bank, Beneficiary Name, Account Number).

3. One-Click Value Generators: Fields requiring STANs or transaction references provide a refresh button () that generates random, realistic, collision-free codes.

4. Authoritative Final Text: The pattern preview updates in real time. The final textarea below can be freely modified or added to. Click "Re-sync from Fields" anytime to reset back to compiled values.

Section 6

Counterparty Presets

Avoid typing repetitive counterparty banking details:

To Save a Preset: Fill out the dynamic fields for a common counterparty (e.g. Apex Trading). Click "+ Save Current as Preset", assign a name, and save.

To Use a Preset: Whenever you select that template in future entries, open the Reusable Counterparty Preset dropdown. Choosing the preset fills all fields instantaneously.

Section 7

Ledger, Editing & Voiding Transactions

Access the complete financial history by clicking Ledger.

Editing Transactions: Click "Edit" on any active transaction. You can modify amounts, date, reference, or narration. When amounts are updated, the account balance adjusts dynamically.
Voiding Transactions: Financial records cannot be hard deleted. Clicking "Void" prompts for a mandatory reason. The transaction status is marked as voided, amounts are excluded from portfolio balances, and the event is logged to the system audit trail.
Section 8

Account Statements & Bank Presentation Formats

Under Statements, users can generate institutional account statements across multiple presentation formats. ATM Ledger enforces strict separation between financial calculation and layout rendering: regardless of the chosen layout, opening balances, running balances, debits, credits, and closing totals are 100% identical and mathematically verified via BCMath.

Standard Bank Statement

Clean, modern tabular ledger statement featuring summary statistics, account badges, reference instrument numbers, and transaction breakdown.

Default Format
HBL Statement Layout

Dense institutional layout inspired by authentic Habib Bank Limited account statements. Designed for official printing and client presentation.

Active Format
HBL Statement Layout Features:
  • Header: Prominent YOUR ACCOUNT STATEMENT title with uppercase period range (e.g. JUL 01, 2025 TO JUN 30, 2026).
  • Two-Column Structure: Customer name and address on the left; dense metadata table on the right displaying Account No, Branch, Account Type, Currency, Printing Date, Frequency (INTERIM / DUPLICATE), Page No, and User ID.
  • Brought Forward Row: The transaction table initiates with a dedicated BROUGHT FORWARD row showing the opening balance.
  • Table Columns: Fixed banking columns: DATE, VALUE, PARTICULARS, DEBIT, CREDIT, and BALANCE.
  • Multi-Line Particulars: Long narrations wrap naturally across multiple lines without truncating or stretching table margins.
  • Bank Logo Integration: Automatically renders the official HBL logo configured in Bank Master, or a clean typography badge if no logo is uploaded.
  • Footers: System-generated non-signature disclaimer and multi-page continuation indicators.
Printing & PDF Export Workflow: Click "Print / PDF View" on either format to open an A4 print-optimized document. Press Ctrl + P (or click the green Print button) to save as an official PDF. Margins, repeating headers (thead { display: table-header-group; }), and page breaks are handled automatically.
Section 9

Bank Master & Administration

Administrators have access to global management portals:

  • Bank Master (/banks): Add new institutions, upload bank logos (PNG/JPG/WEBP ≤ 2MB), edit codes, or deactivate banks. Logos appear automatically on account statements and bank catalogues.
  • Templates (/templates): Define narration patterns, token placeholders, field validation rules, and default options.
  • Users (/users): Register new accounts, update roles (User/Admin), adjust statuses, and execute secure password resets.
